## Multi-server fleet (up to 10 matches)

- **api** (`combatforge-api/src/directory.ts`): ONE fleet key now backs N instances — rows keyed
  `<serverId>#<port>`; register/heartbeat/unregister carry `port` (port-less legacy calls match
  key-wide so the alpha-15 box keeps working against the new api until redeployed). List JOIN
  matches bare or suffixed ids; display name gets ` #N` (port − 7776) only when a key runs >1
  instance. **Tom deploys: `npx wrangler deploy` in `D:\projects\combatforge-api`.** No D1
  schema change.
- **game**: heartbeat + unregister now send `port` (`PFBackendSubsystem.cpp`).
- **client browser**: 12 rows in a ~3.5-row-tall scroll box; `START NEW MATCH` button joins the
  first EMPTY compatible server (the joiner becomes match leader and sets it up).
- **box**: `Start-Fleet-OnBox.ps1 -Instances N` (spawns N windows of `Start-Server-OnBox.ps1
  -Port 7777+i -InstanceIndex i`; instance ≥2 data dirs = `ProgramData\CombatForge\InstanceN`);
  `Deploy-OnBox.ps1 -Instances N` pulls + launches the fleet. serve/ copies refreshed.
- **RAM reality**: vc2-4c-8gb ≈ 3-4 instances; the full 10 needs a ~16-24 GB box. The fleet
  script prints a fit estimate and warns on overcommit.

## Forced 3-match cycle (Creative → Remix → Remix Swap)

- `GS->CycleStage` (replicated) + GameMode `NextCycleStage`/`LastMatchPieces`. Active whenever
  BuildMode ≠ PlayOnly and MatchType ≠ FFA (official + LAN alike).
- Stage 1 builds from scratch; stages 2/3 inject the map **just played** (in-memory snapshot at
  Build→Combat freeze — pre battle damage); community-arena pick is the fresh-server fallback.
- **Remix Swap flips every human's TeamId** before bots fill: squads move to the other plot and
  own the fort the other squad built (piece Team ids untouched, so plot rights/colors line up).
- Advances at Results (Lobby + browser already advertise the UPCOMING stage); host mode pick
  rewinds the wheel (Remix enters at stage 2); force-return-to-lobby / empty-server reset it.
- **UI**: `PFCycleBar` (1 CREATIVE | 2 REMIX | 3 REMIX SWAP, filled to current stage) embedded
  in Tab scoreboard, Esc options, lobby. Server rows show it via the heartbeat `mode` label
  ("Skirmish · Remix Swap") — zero directory changes.

## Combat / movement

- **Window/ledge fire fix**: `PFAdjudicateShotOrigin` — if the eye→muzzle path is blocked
  (barrel in a frame) OR the muzzle's first 250uu toward the aim point clips what the eye-line
  doesn't (sills/ledges), the shot re-originates at the EYE. Server accepts origins near muzzle
  OR eye (same 200uu tolerance).
- **ADS sens**: `pf.ADSSensScale` (default 0.75) — focal-length scaling eased with the zoom
  (~0.57× irons, ~0.34× sniper glass on a 105° base). Multiplies the global sensitivity option.
- **Shotgun feel**: +25% visible kick (viewmodel + camera shake) for Pellets>1; aim-climb
  untouched (balance).
- **Crouch 58→48 half-height** (96uu tall): fits the ramp underfill tunnel + the wall/ramp
  triangle gap; standing (176) still blocked. Fixes ramp-base bomb defuses (defuse is pure
  260uu distance — no LOS — approach was the blocker).
- **Last 30 s**: big top-center countdown (per-second pop) + music fades to silence
  (`UPFMusicSubsystem::SetMatchEndDucked`, AdjustVolume — no tick), keyed to the live round
  timer; new round/phase restores.
